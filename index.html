Security

DST: Deterministic Security Testing

Static analysis that does more than flag possible vulnerabilities: for each finding it produces a proof certificate with the payload, how to deliver it, and how to check that it worked. There is no machine learning in the detection loop, so the same code gives the same report every time.

  • Parses source code with tree-sitter into a graph of data flows.
  • Checks hundreds of CWE properties against that graph, across Java, JavaScript, TypeScript, Python, Go, Rust, PHP, C#, Ruby, Kotlin and Swift.
  • Runs on your own machine from the command line.

Source and documentation on GitHub

Streaming

AI streamer (Agentic Streamer)

A desktop companion for live streamers. It runs on the streamer's own computer next to OBS Studio, and lets an AI agent the streamer chooses help build and run the stream: making scenes and overlays, staging them for the streamer to check before they go on air, and keeping up with chat.

  • Connects to OBS Studio on the same computer.
  • With the streamer's permission, connects to their YouTube channel to read their live chat and post messages to it.
  • Keeps its settings, sign-ins and logs on the streamer's computer.
